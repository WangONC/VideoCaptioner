# LLM API 配置

字幕断句、校正和大模型翻译需要配置可用的模型服务。可以使用服务商官方 API、其他 OpenAI 兼容接口，或支持兼容接口的本地服务。本分支不指定或推广中转站。

## 配置步骤

1. 在所选服务商的官方平台申请 API Key；本地服务按其说明配置。
2. 在软件设置中填写 API 接口地址（Base URL）和 API Key。是否需要 `/v1` 以服务商文档为准。
3. 检查连接，并选择账号实际有权限调用的模型。
4. 根据服务商的并发与速率限制设置线程数。遇到限流应降低并发，而不是直接拉满。

## 常见服务

- [OpenAI](https://platform.openai.com/)
- [DeepSeek](https://platform.deepseek.com/)
- [SiliconFlow](https://cloud.siliconflow.cn/)
- [Ollama](https://ollama.com/)

具体模型名称、价格、额度和支持能力以各服务的当前说明为准。连接成功不代表所有模型均可用；请先用少量字幕测试。

## 数据与密钥

配置在线服务后，参与断句、校正或翻译的字幕及相关提示文本会发送给该服务。请选择自己信任的服务，不要在截图、日志或仓库中公开 API Key。
